# Security Policy

MyButlerDid.it takes security and privacy issues seriously.

## Reporting a vulnerability

Please do not disclose security vulnerabilities, credentials, tokens, personal data or other sensitive information in a public GitHub issue.

Use the security contact and guidance published at:

https://mybutlerdid.it/security

If you are already signed in to MyButlerDid.it, you may also use the support/feedback route available from your Butler account.

When reporting an issue, include enough detail to reproduce and assess the problem, but do not include real user secrets or unnecessary personal data.

## Scope of this repository

This repository contains only the public Claude-facing wrapper for MyButlerDid.it. The production Butler application, database implementation, OAuth internals, infrastructure configuration and commercial backend are not published here.

A vulnerability affecting the remote MCP service, authentication, privacy boundaries or stored Butler data is still relevant even if the affected implementation is not contained in this repository. Please report those issues through the security route above.
