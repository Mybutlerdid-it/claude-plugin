# MyButlerDid.it Claude connector support

## General support

For connector setup questions, reproducible bugs, or feature feedback, open an issue in this public repository:

https://github.com/Mybutlerdid-it/claude-plugin/issues

Please include the Claude surface you were using, the action you were attempting, and the error or unexpected result. Do not include credentials, access tokens, private household information, or unnecessary personal data.

## Security or privacy-sensitive reports

Do not use a public GitHub issue for vulnerabilities, credentials, tokens, personal data, or other sensitive material.

Use the security reporting guidance at:

https://mybutlerdid.it/security

## Account and data controls

Butler account controls remain the source of truth for household membership, privacy, export, deletion, and connector disconnection. See:

https://mybutlerdid.it/privacy
